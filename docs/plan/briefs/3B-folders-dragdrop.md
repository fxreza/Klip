2. **Delete**: context menu "Delete Folder…" / `keyDeleteFolder()`: if the folder is empty -> delete immediately (scope falls back to `.all`). If not empty -> `DeleteFolderPrompt` with: "Move N clips to All" (default, `.moveItemsOut` - note they stay locked; say so in the prompt) / "Delete N clips" -> if any are locked, a second explicit step in the same card: "M of them are locked. 3. **Move**: `moveSelection(toFolder id: UUID?)` (selected or multi-selected ids; `nil` = remove from folder), `keyMoveToFolder()` opens a `MoveToFolderPrompt` (PromptCard list of folders + "Remove from folder", arrow keys + Return, typing filters). 4. **New folder**: keep 2A's `NewFolderPrompt`; add `keyNewFolder()`; after creating, select the new folder scope.
5. **Drag and drop**: drag one or several selected rows onto a sidebar folder row (and onto "All" = remove from folder). A click without movement must still behave exactly as before (select / ⌘ / ⇧ / double-click).
