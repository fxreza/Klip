- **5A-04** (Critical) capture of huge text freezes the UI (5 s for 15 MB): in `ClipboardWatcher` text branch, cap what goes into `ContentDetector` (first 64 KB) and make detection cheap for large inputs; do the RTF/flavors/large-text file writes off the main thread (the watcher may stay on the main run loop for the pasteboard read itself, but all hashing of > 1 MB strings, detection and disk writes move to a utility queue, then `store.add` on main).
